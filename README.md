# 🏀 이 NBA 선수는 누구? (Guess This NBA Player)

NBA 역대 레전드부터 현역 스타까지, 트리비아 힌트를 보고 어떤 선수인지 맞추는 게임입니다.
힌트를 **적게** 보고 맞출수록 점수가 커지고, 최종 점수로 **글로벌 리더보드**에 도전할 수 있습니다.

## 게임 규칙

- 한 게임은 **5라운드**, 라운드마다 선수 한 명이 무작위로 출제됩니다.
- 힌트는 라운드당 최대 **5개**가 어려운 것부터 하나씩 공개됩니다.
- 공개된 힌트 수에 따라 획득 점수가 달라집니다:

  | 본 힌트 수 | 1개 | 2개 | 3개 | 4개 | 5개 |
  |---|---|---|---|---|---|
  | 점수 | **100** | 80 | 60 | 40 | **20** |

- **오답**을 내면 다음 힌트가 자동으로 공개됩니다 (= 기회 소진). 5번째 힌트에서도 틀리면 그 라운드는 0점입니다.
- 만점은 **500점**. 게임이 끝나면 닉네임으로 리더보드에 기록을 등록할 수 있습니다.

정답은 한글/영문 이름 모두 인정되며(예: `스테픈 커리`, `Stephen Curry`, `커리`),
대소문자·공백·문장부호는 무시됩니다. 입력창에 자동완성도 지원됩니다.

## 실행 방법

Node.js 18 이상만 있으면 됩니다. **외부 의존성이 전혀 없습니다.**

```bash
npm start          # http://localhost:3000
PORT=8080 npm start  # 포트 변경
```

## 테스트

```bash
npm test
```

게임 시작 → 오답/힌트/포기/정답 → 게임 종료 → 리더보드 등록까지 전체 흐름을 검증하는 통합 테스트가 실행됩니다.

## 구조

```
server.js                # 의존성 없는 Node HTTP 서버 (API + 정적 파일)
data/players.js          # 선수 데이터 인덱스 (총 200명 × 힌트 5개, 어려운 순 + 허용 별칭)
data/players-legends.js  # 클래식 레전드 (1950~80년대 초)
data/players-8090s.js    # 1980~90년대 스타
data/players-2000s.js    # 2000년대 스타
data/players-2010s.js    # 2010년대 스타
data/players-current.js  # 현역 스타
public/                  # 프론트엔드 (바닐라 JS SPA)
test.js                  # 통합 테스트
```

서버는 시작 시 선수 데이터를 검증합니다: 힌트 개수(정확히 5개), 선수 id 중복,
그리고 정규화된 이름/별칭이 서로 다른 선수와 충돌하지 않는지 확인하며, 문제가 있으면 즉시 실패합니다.

### 설계 포인트

- **치팅 방지**: 정답과 점수 계산은 전부 서버에서만 처리합니다. 클라이언트에는 공개된 힌트만 전송되며, 점수를 클라이언트가 보고하는 일이 없습니다.
- **리더보드 영속화**: `data/leaderboard.json`에 저장됩니다 (git에는 포함되지 않음). 상위 100개 기록을 유지하고 상위 20개를 노출합니다.
- **게임 세션**: 메모리에 보관되며 2시간 후 자동 만료됩니다.

## API

| 메서드 | 경로 | 설명 |
|---|---|---|
| `GET` | `/api/players` | 자동완성용 선수 이름 목록 |
| `GET` | `/api/leaderboard` | 상위 20위 랭킹 |
| `POST` | `/api/game` | 새 게임 시작 |
| `POST` | `/api/game/:id/guess` | 정답 제출 (`{"guess": "..."}`) |
| `POST` | `/api/game/:id/hint` | 다음 힌트 공개 |
| `POST` | `/api/game/:id/giveup` | 현재 라운드 포기 |
| `POST` | `/api/game/:id/submit` | 게임 종료 후 리더보드 등록 (`{"name": "..."}`) |
